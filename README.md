# GitHub User Info

Консольная программа на Python: вводишь имя пользователя GitHub и получаешь логин и количество публичных репозиториев.

## Возможности
- Запрос к GitHub API через библиотеку `requests`
- Проверка кода ответа: 200 (найден), 404 (не найден), другие коды
- Обработка ошибок сети через `try / except` (нет интернета, неверный адрес, долгий ответ)

## Запуск
1. Установите Python 3.12
2. Скачайте проект:
```
git clone https://github.com/ZenchinAlex/github-info.git
cd github-info
```
3. Создайте виртуальное окружение и установите библиотеки (Windows, PowerShell):
```
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
4. Запустите:
```
python main.py
```

## Пример
```
Введите имя пользователя GitHub: torvalds
Логин: torvalds
Репозиториев: 12
```
Если такого пользователя нет:
```
Пользователь не найден
```
Если нет связи с сервером:
```
Нет связи с сервером. Проверьте интернет и адрес
```
